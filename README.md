# LeaveAutomation-CNT (STAFF TIME AUTOMATION)
🍍 PINEAPPLE & COCONUT PROJECT (CN.1856 / 11867) 🥥

ระบบตรวจสอบและบันทึกข้อมูลการลา & ใบแจ้งการมาทำงานลงไฟล์ STAFF TIME อัตโนมัติ (STAFF TIME Automation Tool) พัฒนาด้วย Python และ CustomTkinter สำหรับฝ่ายบุคคลและผู้บริหารโครงการ CNT

### ✨ ฟังก์ชันและความสามารถหลัก (Key Features)

1. **บันทึกการลาอัตโนมัติ (Approved Leave Import):**
   - รองรับไฟล์ข้อมูลการลา `.xlsx` บันทึกรหัสวันลา (เช่น พ, ลป, ลก, บ, ค, ส) ลงช่องตามวันและเงื่อนไขบริษัท
2. **บันทึกใบแจ้งการมาทำงาน (Attendance Import):**
   - คำนวณเวลาเข้า-ออกตามกฎบริษัท ปัดเศษเวลาออกทีละ 30 นาที และปัดขึ้นเป็น 16:30 ขั้นต่ำ
3. **ระบบตรวจสอบและกันพลาด 5 ชั้น (Safeguards):**
   - ป้องกันเขียนทับวันลาที่มีอยู่แล้ว, ป้องกันเขียนผิดคน, ป้องกันทับวันหยุดบริษัท, ทำงานแบบ Atomic
4. **พรีวิวก่อนประมวลผล (Pre-Check Preview):**
   - แสดงสถิติและผลลัพธ์ที่จะเกิดขึ้นล่วงหน้า 100% ก่อนตัดสินใจบันทึก
5. **วิเคราะห์เวลาผิดปกติอัจฉริยะ (Smart Anomaly Analyzer):**
   - ตรวจจับสแกนขาเดียว (Missing Punch) และไม่พบสแกน/ไม่ลา (Unrecorded Absence)
   - จัดกลุ่มตามชื่อพนักงาน หากมีหลายวันจะเรียงติดกันตามลำดับวันที่
   - กรอกข้อมูลลงชีท **"ไม่มีแจ้งในระบบ"** ตามแบบฟอร์มมาตรฐานบริษัท หรือส่งออกเป็นไฟล์ใหม่ในคลิกเดียว
6. **ระบบอัปเดตอัตโนมัติ (Auto-Updater):**
   - ตรวจสอบและดาวน์โหลดอัปเดตเวอร์ชันใหม่จาก GitHub Releases ได้โดยตรงภายในโปรแกรม
