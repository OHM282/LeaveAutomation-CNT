# LeaveAutomation-CNT (STAFF TIME)
🍍 PINEAPPLE & COCONUT PROJECT (CN.1856 / 11867) 🥥

ระบบบันทึกข้อมูลการลา & แจ้งเวลาทำงานอัตโนมัติ (STAFF TIME Automation Tool) พัฒนาด้วย Python และ CustomTkinter ออกแบบสำหรับโครงการ CNT

## ✨ ฟังก์ชันหลัก
1. **บันทึกการลาอนุมัติอัตโนมัติ:** นำเข้าไฟล์ `อนุมัติ.xlsx` และลงรหัสวันลาตามกฎของโครงการ
2. **บันทึกใบแจ้งเวลา (ลืมสแกนนิ้ว):** นำเข้าไฟล์ `ใบแจ้งการมาทำงาน.xlsx` พร้อมกฎปัดเศษลง 30 นาที
3. **ระบบกันพลาด (Safeguards):** ข้ามแถวที่สแกนครบ, ตรวจจับข้อมูลขัดแย้ง, ตรวจสอบชื่อ-รหัสพนักงาน
4. **ตรวจสอบก่อนบันทึกจริง (Pre-Check Preview):** ดูรายการแก้ไขทั้งหมดก่อนเขียนลงไฟล์จริง
5. **Auto-Update ผ่าน GitHub Releases:** ตรวจสอบและอัปเดตเวอร์ชันใหม่ได้ในคลิกเดียว
